# Contributing

Thanks for your interest in JARVIS! The project is in its planning phase, so ideas and feedback in issues are the most useful contributions right now.

## Before you contribute code

- **Contributor License Agreement.** Code contributions will require signing a CLA ([why](docs/DECISIONS.md#d6-agpl-30-core-mit-client-libraries-cla-for-contributors)). The CLA process will be set up before the first external pull request is merged.
- **Licensing.** Contributions to the engine and dashboard are licensed under AGPL-3.0. Contributions to `packages/sdk` and `packages/react` are licensed under MIT.
- **Read the decisions.** [docs/DECISIONS.md](docs/DECISIONS.md) explains choices that are deliberately fixed. To challenge one, open an issue first.

## Ground rules

- **No terms-of-service violations.** Pull requests that scrape Google Maps, social networks or other services against their terms will not be accepted. Use official APIs.
- **No automated outreach** outside the explicitly planned, opt-in features.
- **Keep changes small and focused**, with tests for logic in `packages/core`.
